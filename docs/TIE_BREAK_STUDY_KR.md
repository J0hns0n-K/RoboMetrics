# A* 동점 처리 비교 — 2026-10-28

## 학생의 원래 의견

실험 전 학생은 다음과 같이 말했다:

> 난 둘 다 똑같다고 봐. 내가 봤을 때는 여기까지 온 거리나 남은 예상 거리는 별로 중요치 않은 것 같아. 합계만 같으면 상관없는 것 같아.

합계가 같으면 A*의 기본 점수에서는 동점이라는 설명은 맞다. 학생은 새로운 처리 규칙을 고르거나 검토 칸 수·성공 수의 차이를 수치로 예측하지 않았다. 이 응답을 임의로 ‘계산량 변화가 정확히 0이다’라는 수치 가설로 바꾸지 않는다.

## AI가 구체화한 비교 질문

합계가 같은 후보를 고르는 순서만 바꾸면, **성공한 경로의 최단거리**는 유지하면서 **검토하는 칸 수와 예산 내 성공 수**가 달라지는가?

- 기존 FIFO: 합계 `g+h`가 작으면 먼저, 합계가 같으면 먼저 들어온 후보부터.
- 대안 closer-goal: 합계가 작으면 먼저라는 규칙은 동일. **동점일 때만** 목표까지의 예상 거리 `h`가 작은 후보부터. 그래도 같으면 FIFO.

대안은 AI가 제시하고 구현한다. 같은 합계에서 `h`가 작다는 것은 `g`가 크다는 것과 같으므로, 코드의 두 번째 비교는 `b.g-a.g`를 사용한다. 이 보조 비교는 A*에서 동점일 때만 적용된다. Greedy나 Dijkstra, 이동 비용·휴리스틱·이웃 순서·목표 확인·닫힌 집합 처리는 바꾸지 않는다. 기본값은 여전히 FIFO다.

## 통제와 평가 계획

`experiments/tie-break.protocol.json`에 학생 원문, AI의 구체화, 방법과 표시할 조건을 실행 전에 보존한다. 기존 `data/batch/early-matrix-run-01.json`의 채택 seed를 그대로 쓴다. 밀도마다 같은 30장, 같은 예산 75/120/180/300, 같은 출발점/도착점을 사용하며 지도를 다시 뽑지 않는다.

기존 기본 A*와 Greedy 결과 720개가 이전 원시 행과 같아야 한다. 성공한 두 A* 변형의 경로는 유효하고 Dijkstra 기준 최단거리와 같아야 한다. 성공 수/30, 실패도 포함한 평균 검토 칸 수, 공통 성공 분모와 경로 길이, 성공 증가와 감소를 모두 기록한다. 불리한 조건을 제거하지 않는다.

표시할 대표 조건은 이미 앞에서 사용한 밀도 .19/예산 120의 성공 수와, 예산 300에서 완료된 탐색의 검토 수다. 전체 12개 조건도 모두 보고한다. 제한이 있는 평균은 실패 사례에서 검토가 잘린다는 점을 유의한다. 검토 수는 실행 시간이나 로봇 에너지와 동일하지 않다.

## 실행 및 기여

```sh
node scripts/compare-ties.mjs experiments/tie-break.protocol.json .git/evidence/tie-break-run-01.json "AI assistant"
```

AI가 작성한 변형·검사·도구로 실행한다. 원시 JSON/CSV와 검사 출력은 `data/tie-break/`에 보존한다. 학생은 위 의견과 이후 실제로 제공한 해석을 기여한다. 동점 처리는 기존에 알려진 기법이며 새 알고리즘 발명이나 학생의 독립 구현으로 주장하지 않는다. 작은 지도 검사는 동작을 확인하는 AI의 대조 사례이며, 아직 보지 않은 여러 지도 결과에 대한 학생의 독립 예측으로 취급하지 않는다.

## 결과

입력과 구현을 보존한 source `260ac09d063c422b92acef8ad4a6afbb622429f7`에서 AI가 실행했다. 실험 입력은 커밋된 상태였고, 별도의 `practice/02-planning-budget.mjs` 작업 파일 변경은 그대로 남겨 `workspaceDirty: true`로 기록했다. 실험 입력 변경 여부는 `experimentInputsDirty: false`다. 전체 작업 폴더가 깨끗했다고 기술하지 않는다.

기존 기본 A*/Greedy의 원시 결과 720개가 모두 재현됐고, 전체 검사 19개가 통과했다. 두 A* 변형의 성공한 경로는 이번 코호트에서 모두 기준 최단거리와 같았다. 새 검사는 기존 4×3 전수/BFS 검증을 바탕으로 동점 변형도 1,024개 장애물 배치에서 도달 가능성·최단거리·예산 경계가 맞는지 확인했다.

작은 3×3 지도에서는 두 규칙 모두 같은 4번 경로를 찾았지만 검토한 칸은 FIFO 8칸, closer-goal 5칸이었다. 사전에 표시하기로 한 밀도 .19/예산 120에서는 성공 수가 FIFO 15/30, 대안 30/30이었다. 예산 300에서는 둘 다 같은 30장에 성공했고, 평균 검토 수는 118.7667→36.9667로 줄었으며 평균 이동 거리 26.0667은 같았다. 이것은 이 조건에서의 검토 노드 수 변화이며 실행 시간·에너지의 측정 결과가 아니다.

전체 12조건 표는 `TIE_BREAK_RESULTS.md`에 있고, 성공 증가·감소를 모두 보존했다. 이번 코호트에서 성공이 줄어든 조건은 관측되지 않았지만 보편적인 우월성을 증명하지 않는다. 여러 예산은 같은 지도를 재사용한다. 기본 규칙은 여전히 FIFO이며, 대안은 명시적으로 선택하는 실험 옵션이다.

학생이 말한 ‘합계 점수가 같다’는 사실과 ‘검토량도 같다’는 주장은 서로 다르다. 이 비교는 AI가 두 번째 질문을 구체화해 수행한 것으로, 학생이 말하지 않은 수치 가설을 기각했다고 설명하지 않는다. 결과를 본 학생의 추가 해석은 아직 수집 전이다.

## 관련 기존 연구와 범위

Asai와 Fukunaga의 [AAAI 2016 논문](https://ojs.aaai.org/index.php/AAAI/article/view/10071)은 휴리스틱 값 등을 사용하는 A* 동점 처리 전략을 실험했다. 그 논문의 주요 결과는 영비용 연산이 있는 영역을 다루므로, 양의 단위 이동 비용인 이번 격자 결과의 효과 크기를 그 논문에서 가져오지 않는다. 여기서는 동점 처리가 기존 연구 주제임을 밝히는 배경으로 인용하며, 이번 수치는 자체 원시 실험 결과에 근거한다.
