# 여러 지도에서의 비교 — 2026-10-28

## 학생의 실행 전 생각

학생은 처음에 다음과 같이 답했다:

> A*  / 이때까지 결과를 보면 주로 A* 이 Greedy보다 더 짧은 루트를 만들어줬어. 근데 더 자주 도착경로를 찾는다는게 뭔지 모르겠네

AI가 경로 길이와 성공 횟수(같은 계산 제한에서 30장 중 몇 장에서 도착 경로 하나라도 찾는가)를 구분해 설명한 뒤, 성공 횟수 예상은 **아직 모르겠어**라고 답했다. 따라서 경로 길이에 대한 예상은 A* 쪽이지만, 성공 횟수에는 사전 선택이 없다. 초기 A* 답을 성공률에 대한 틀린 예측으로 처리하지 않는다. 원문은 실행 전에 프로토콜 JSON에 보존한다.

## 기존 프로토콜의 첫 전체 실행

`experiments/early-matrix.protocol.json`은 2026-10-27 참고 프로토콜의 조건을 유지한다: 16×12 지도, 기준 seed 20261027, 생성 확률 .12/.19/.28, 검토 예산 75/120/180/300, 밀도마다 도달 가능한 지도 30장. 총 12개 조건이다.

동일 밀도에서는 모든 예산과 두 알고리즘이 같은 지도 30장을 사용한다. 밀도별 코호트 항목은 90개이며 예산별 재사용으로 360개 지도/예산 조건, 720개 정책 실행이 생긴다. 이를 독립 지도 360장이나 독립 표본 720개로 해석하지 않는다. 밀도가 달라지면 도달 가능성으로 걸러진 seed 목록도 달라질 수 있다.

## AI 도구의 방법 보강

원본 `src/core.mjs`와 `benchmark`는 바꾸지 않는다. AI가 작성한 `scripts/run-matrix.mjs`는 원래 벤치마크를 호출하고, 후보 seed를 다시 확인해 도달 불가로 제외한 지도 수와 seed를 기록한다. 예산별 채택 지도가 같은지도 검사한다. 도달 가능한 지도만 뽑는 조건부 표본이라는 제한을 없애는 것은 아니다.

각 조건에서 다음을 보존한다:

- 예산 내 성공 수 / 30: 경로가 최단이 아니어도 찾으면 성공이다.
- 원래의 성공 사례별 평균 이동 횟수와 그 분모: 두 방법의 성공 지도가 다를 수 있다.
- 둘 다 성공한 같은 지도에서의 경로 길이 차이와 공통 분모: 성공 집합 차이를 섞지 않는 보조 비교다.
- 예산 안에서 최단경로까지 찾은 수 / 30: 도착 경로만 찾았는지와 별개 항목이다.
- 전체 사례의 평균 검토 칸 수, 원시 행, 채택/탈락 seed, 조건·소스 해시와 실행 주체.

## 실행과 기여 구분

입력과 도구를 먼저 커밋하고 검사한 뒤 실행한다. 출력은 덮어쓰지 않는 새 이름을 쓴다:

```sh
node scripts/run-matrix.mjs experiments/early-matrix.protocol.json .git/evidence/early-matrix-run-01.json "AI assistant"
```

같은 이름의 CSV 요약도 생성한다. 최종 원시 JSON/CSV와 테스트 출력은 `data/batch/`에 보존한다. 이전 단일 조건 참고 결과는 이미 봤으므로, 이 실행을 모든 결과를 전혀 모른 상태의 새 사전등록 연구로 주장하지 않는다.

프로토콜의 원래 조건, 코호트 감사, 집계 구현, 실행은 AI 지원이다. 학생은 위 응답과 이후 실제 결과 해석을 제공한다. 학생 코드 작성이나 독립 실행으로 추정하지 않는다. 이는 합성 격자 실험이며 물리 로봇 연구가 아니다.

## 첫 실행 완료

입력·응답·도구를 보존한 clean source `2dda59173bfc99ce0c9ad418f3724edf621d6a1e`에서 AI가 전체 12개 조건을 실행했다. 16개 테스트가 모두 통과했다. 전체 결과표는 `MATRIX_RESULTS.md`, 원시 JSON/CSV·테스트 원문·SHA256 검증표는 `data/batch/`에 있다.

밀도 .19의 같은 지도 30장에서, 예산 120일 때 성공 수는 A*=15, Greedy=30이었다. 둘 다 성공한 15장만 비교하면 평균 이동은 A*=26.0, Greedy=27.6이었다. 예산 300에서는 둘 다 같은 30장에서 성공하며 평균 이동은 A*=26.0667, Greedy=28.4였다. 성공 횟수와 경로 길이를 혼동하지 않는다. 성공 횟수에 대한 학생 사전 예상은 없었으므로 이 결과를 학생 예측의 반증으로 설명하지 않는다.

밀도별 채택 30장을 얻는 동안 .12에서는 후보 30장/탈락 0장, .19에서는 34장/4장, .28에서는 56장/26장이었다. 따라서 결과는 전체 생성 지도가 아니라 도달 가능한 지도에 조건을 둔다.

AI가 사후에 세 실패/경로품질 사례를 골라 전체 경로를 재생성하고 원래 행과 일치하는지 확인했다. 기록은 `data/batch/failure-reports.json`에 있다. 이것은 새 독립 표본이나 학생이 발견한 사례가 아니다.
