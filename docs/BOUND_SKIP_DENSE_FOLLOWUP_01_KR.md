# 벽이 많은 새 조건에서 하한 생략 검증

2026-10-29. 학생은 새 지도 조건 중 **1, 벽이 많은 조건**을 골랐다. [선택 원문](../data/learning/bound-skip-followup-density-01.json)은 조건 선택만 기록하며 성능 예측으로 확대하지 않는다. 벽 생성 확률 .28은 AI가 앞선 선택지에서 정한 수치다. 실제 수락 지도마다 벽 비율이 정확히 28%라는 뜻은 아니다.

## 실행 전 고정한 방법

[취득 프로토콜](../experiments/bound-skip-dense-followup-acquisition-01.protocol.json)과 [비교 프로토콜](../experiments/bound-skip-dense-followup-comparison-01.protocol.json)을 새 지도 생성 전에 함께 커밋한다. 기준 시드 20265027, 16×12, 생성 확률 .28, 연결되고 벽이 있는 첫 30장과 후보 탈락 감사를 고정한다. 기존 경로 취득·한 벽 제거 규칙·A* FIFO·호출별 예산 300·시작과 목표·단위 비용은 이전 방법을 유지한다.

1. 기존 배치 도구로 오프라인 기존 경로와 생략 없는 기준 결과를 확보한다. 이 도구는 원래 프로토콜 재현을 위해 하한 생략을 명시적으로 끈다. 기존 경로 취득 계산은 정책 비용과 분리한다.
2. 확보한 기준 데이터를 새 이름으로 커밋한다. 이후 같은 수정 지도·기존 경로에서 강제 재탐색과 생략 적용을 각각 새로 실행한다. 입력 선택을 다시 하지 않는다.
3. 경로 유효성·길이·BFS 최단 거리, 수학적 증명으로 생략한 수와 실제 탐색 완료 수, 예산 실패와 유효 경로 보존, 새 검토량·호출 수를 구분한다. 기준 방식의 원래 결과 필드도 재현되는지 확인한다.

규칙과 코드는 이 새 코호트를 보기 전에 고정했다. 이 조건은 개발에 사용한 .19 코호트의 단순 재비교와 구분하지만, 다른 시드라는 이유만으로 통계적 독립성을 보장하지 않는다. 또한 시드와 밀도가 함께 바뀌므로 두 연구의 차이를 밀도 하나의 효과로 해석하지 않는다.

코드 변경 없이 기존 55개 테스트에 연결된 소스를 재사용한다. 이번 설정에서 전체 테스트를 새로 실행한 것으로 표시하지 않는다. 실행 단계·입력·소스 해시, 원시 결과와 별도 검증을 보존한다. 학생은 조건을 골랐고 방법·코드·실행·최초 분석은 AI 지원이다. 결과는 아직 없으며 과거 원시 자료를 덮어쓰지 않는다.
