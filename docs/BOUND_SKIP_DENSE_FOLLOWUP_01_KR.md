# 벽이 많은 새 조건에서 하한 생략 검증

2026-10-29. 학생은 새 지도 조건 중 **1, 벽이 많은 조건**을 골랐다. [선택 원문](../data/learning/bound-skip-followup-density-01.json)은 조건 선택만 기록하며 성능 예측으로 확대하지 않는다. 벽 생성 확률 .28은 AI가 앞선 선택지에서 정한 수치다. 실제 수락 지도마다 벽 비율이 정확히 28%라는 뜻은 아니다.

## 실행 전 고정한 방법

[취득 프로토콜](../experiments/bound-skip-dense-followup-acquisition-01.protocol.json)과 [비교 프로토콜](../experiments/bound-skip-dense-followup-comparison-01.protocol.json)을 새 지도 생성 전에 함께 커밋한다. 기준 시드 20265027, 16×12, 생성 확률 .28, 연결되고 벽이 있는 첫 30장과 후보 탈락 감사를 고정한다. 기존 경로 취득·한 벽 제거 규칙·A* FIFO·호출별 예산 300·시작과 목표·단위 비용은 이전 방법을 유지한다.

1. 기존 배치 도구로 오프라인 기존 경로와 생략 없는 기준 결과를 확보한다. 이 도구는 원래 프로토콜 재현을 위해 하한 생략을 명시적으로 끈다. 기존 경로 취득 계산은 정책 비용과 분리한다.
2. 확보한 기준 데이터를 새 이름으로 커밋한다. 이후 같은 수정 지도·기존 경로에서 강제 재탐색과 생략 적용을 각각 새로 실행한다. 입력 선택을 다시 하지 않는다.
3. 경로 유효성·길이·BFS 최단 거리, 수학적 증명으로 생략한 수와 실제 탐색 완료 수, 예산 실패와 유효 경로 보존, 새 검토량·호출 수를 구분한다. 기준 방식의 원래 결과 필드도 재현되는지 확인한다.

규칙과 코드는 이 새 코호트를 보기 전에 고정했다. 이 조건은 개발에 사용한 .19 코호트의 단순 재비교와 구분하지만, 다른 시드라는 이유만으로 통계적 독립성을 보장하지 않는다. 또한 시드와 밀도가 함께 바뀌므로 두 연구의 차이를 밀도 하나의 효과로 해석하지 않는다.

코드 변경 없이 기존 55개 테스트에 연결된 소스를 재사용한다. 이번 설정에서 전체 테스트를 새로 실행한 것으로 표시하지 않는다. 실행 단계·입력·소스 해시, 원시 결과와 별도 검증을 보존한다. 학생은 조건을 골랐고 방법·코드·실행·최초 분석은 AI 지원이다. 기준 취득과 하한 적용 비교의 완료 결과는 아래에 있다. 과거 원시 자료를 덮어쓰지 않는다.

[기준 원시 자료](../data/route-update-policy/bound-skip-followup-dense-baseline-run-01.json)를 취득하고 `fd799ad5b645a605fb7cf269157fbd1203861623`에 입력으로 고정한 뒤 양쪽 정책을 실행했다. ## 실제로 짧아진 한 사례도 유지

원래 최단 길이는 26번인 21장, 28번인 7장, 30번인 2장이었다. 벽 제거 후 이론적·실제 단축은 1/30장이다. 시험 4·시드 **20265032**에서 (15,9)의 벽을 없애자 **28→26번**으로 줄었다. 이 이전 길은 하한 26보다 길었으므로 새 정책도 생략하지 않고 재탐색해 같은 개선을 찾았다. 무조건 탐색을 건너뛴 결과가 아니다. 나머지 29장은 길이가 그대로였다. 이는 AI의 결과 확인이며 학생이 미리 예상하거나 독립적으로 발견한 것으로 기록하지 않는다.

예산 300은 격자 칸 수 192보다 크다. 닫힌 칸을 다시 검토하지 않는 현재 코어에서 이번 조건은 작은 예산을 압박하는 실험이 아니다. 향후 예산 제한에 따른 동작과 물리적 제약은 별도 검증이 필요하다.

## 비용·출처와 메타데이터 정정

오프라인 기존 경로 취득은 A* 30회·검토량 2,611이다. 기준 취득 단계의 온라인 재탐색은 별도로 30회·2,690칸, 후보/수정 지도 BFS는 75/30회다. 이후 두 정책 재비교는 평가 60건·새 A* 39회·검토량 3,534이며 기존 경로를 다시 취득하지 않았다. 검증은 BFS 105회·추가 공유 탐색기 0회다. 서로 다른 단계의 비용과 정책별 비용을 섞지 않는다.

재사용한 도구의 [첫 비교 원본](../data/route-update-policy/bound-skip-followup-dense-comparison-run-01.json)은 표제에 이전 개발 코호트용 문구가 남아 있었다. `680ac3d`에서 도구 표제를 프로토콜 범위를 따르도록 고쳤다. 원본은 보존하고 **표제만 정정한 파생본**에 원본 해시·정정 이유·정정 소스와 시각을 추가했다. 원래 실행 소스·시각·프로토콜·수치는 그대로이며 새 탐색·BFS·코호트 생성은 0회다. 정정본을 새 실험·재현 횟수로 세지 않는다.

코어·정책·배치 방법·테스트 소스는 이전 55개 테스트 검증과 동일하다. 새 전체 테스트 실행은 없고, 표제만 바뀐 도구는 문법과 변경 필드 범위를 확인했다. 후보·시드·지도·벽 좌표·경로·BFS·증명/완료 구분·비용·원시 바이트·출력 거부와 정정 계보를 검증했다. 아직 브라우저·센서·로봇 주행에 연결한 결과는 아니다.

## 학생의 보고서 해석과 AI 조건 보완

학생은 결과 설명 뒤 보고서 문장 요청에 다음과 같이 답했다.

> 이미 최단루트를 찾았다면 굳이 더 재검토하지 않아도 됨. 그래서 검토량 확 줄임.

[원문·맥락 기록](../data/learning/dense-followup-conclusion-01.json)은 안내된 사후 해석으로 구분한다. AI가 조건과 지표를 보완한 별도 편집 문장은 다음과 같다. 이는 학생 원문의 직접 인용이 아니다.

> 이번 실험에서는 최신 지도에서 유효하며 이론적 최소 길이를 달성한 경로의 재탐색을 생략해, 강제 재탐색과 같은 경로를 유지하면서 새 노드 검토량을 줄였다.

지도 변경 전에 최단이었던 길이라는 사실만으로 현재의 유효성·최단성을 보장하지 않는다. 이번 코드는 최신 지도에서 남은 경로를 먼저 검사하고 현재 위치·목표의 하한과 길이가 같은 경우만 생략했다. 원문을 바꾸거나 조건 보완·구현·검증을 학생의 독립적 저작으로 확대하지 않는다.

다음 [작은 예산 비교 초안](../experiments/bound-skip-budget-stress.design.json)은 같은 지도·경로에서 예산만 50 또는 100으로 줄여 재최적화 실패와 유효 경로 보존을 구분한다. 학생은 이후 **2**, 100칸을 선택했다. [예산 100 결과](BOUND_SKIP_BUDGET100_KR.md)는 생략 21·새 탐색 완료 6·예산 초과 3과 유효 경로 30/30을 분리해 보존한다. 새 지도나 독립 코호트로 세지 않는다.
