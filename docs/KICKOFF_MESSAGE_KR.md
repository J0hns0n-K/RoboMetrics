# 준모 새 세션 Kickoff 메시지

준모의 Computer Engineering R&D 프로젝트 **RoboMetrics**를 오늘(2026-10-27)부터 시작한다. 첨부 스타터의 README, HANDOFF_CURRENT, 연구 논증, 실험 프로토콜, RD_ROADMAP, ADMISSIONS_HANDOFF를 모두 읽어라.

**즉시 진행할 일**
1. GitHub 학생 개인 계정의 비공개 `junmo-robometrics` 저장소를 만들고 스타터를 최초 커밋으로 업로드한다. 첫 커밋은 반드시 **counselor/AI reference scaffold**라고 기록하고, 학생 작업으로 허위 귀속하지 않는다.
2. 브라우저 실행과 Node unit test를 확인한다. 출처가 '실물 로봇 데이터'가 아닌 **synthetic simulation**임을 이해한다.
3. A*, Greedy Best-First, Dijkstra의 원리와 제약을 직접 설명하고, 반론 가능한 가설을 정리한다.
4. 10/27~10/29 동안 본인이 직접 설계·수정하고 검증한 차별적 기능 최소 1개를 실제 커밋하고, 밀도×탐색 예산 매트릭스로 실험한다.
5. 증거(커밋·테스트·raw JSON·오류 사례·기여 기록)에 근거하여 Early EC 문장을 작성한다. 결과 미검증 상태라면 완성으로 쓰지 않는다.
6. 11월~RD까지 실제 바퀴 로봇의 kinematics, 센서 오차, 제어기, 시뮬레이션 대비 실험을 단계적으로 확장한다. 실제 로봇을 확보하지 못하면 sim-to-real 실험을 진행했다고 주장하지 않는다.

기존 **FlowBench** 및 실제 학교 **상벌점 관리 사이트**와는 다른 프로젝트다. Early 마감은 대학마다 다르므로 각 대학의 공식 시간 기준으로 확인하라. 별도 승인 없는 학교 개인 데이터·생체정보는 사용 금지.

내가 요구하는 것은 겉보기 UI가 아니라, 준모가 직접 설명할 수 있는 공학적 가설, 재현 가능한 실험, 정직한 성과 기록이다.
