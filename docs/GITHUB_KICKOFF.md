# Repository workflow

Repository: https://github.com/J0hns0n-K/RoboMetrics

The repository is connected and development currently uses `main`. The original AI-generated scaffold is preserved in commit `43fa8ec965180532c1fcf4a553309ed350b25277`.

## Recording a change

1. Inspect the working diff and keep unrelated local edits out of the commit.
2. Record the design choice, hypothesis or bug being addressed before running the relevant comparison.
3. Run the relevant checks; preserve experimental inputs, source revision, raw results and failed cases.
4. Commit focused changes with a meaningful message and accurate authorship. Identify AI assistance in the contribution log.
5. Push and verify the remote revision. Use a pull request when a separate review is useful.

## Research work items

- Explain assumptions and threats to validity.
- Compare map families, obstacle densities and search budgets under paired conditions.
- Analyze counterexamples, failed runs and tie-breaking effects.
- Maintain reproducible tests, evidence and contributor roles.

Keep credentials and personal records out of the repository.
