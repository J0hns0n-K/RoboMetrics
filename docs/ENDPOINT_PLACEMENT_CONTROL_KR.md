# 도착점의 빈칸과 몸체 여유는 다르다

학생은 A/B 도착점 선택 질문에 **몰라**라고 답했다. [기록](../data/learning/endpoint-placement-uncertainty-01.json)은 학생이 A를 선택하지 않았음을 명시한다. A 설명·G/A/B 제어·코드·실행·초기 분석은 AI 참고 작업이다. 학생의 독립 입력 설계나 실험으로 바꾸지 않는다.

## 같은 지도의 도착 위치만 변경

사전 [프로토콜](../experiments/endpoint-placement-controls-01.protocol.json)과 소스/불확실성 기록을 `a7a80ab8357435011af8b8aacc5ef0b40c8de610`에서 커밋한 뒤 실행했다. [원시 결과](../data/footprint/endpoint-placement-controls-run-01.json), [검증](../data/footprint/endpoint-placement-controls-validation-01.json)을 보존한다.

이전 새 시드30장 중 trial10/seed20268037의 원래 장애물을 그대로 읽었다. 새 목표로 난수를 다시 생성하거나 벽을 지우지 않는다. 출발(1,3), 원래9×7 세계, 지름0.8/각 측면 여유0.15, 유효 반지름0.55, 접촉 금지, A* FIFO, 단계별100을 유지하고 도착만 G(7,3)/A(7,2)/B(7,4)로 각각 설정했다. 하나의 알려진 지도에서3개 목표 설정/6정책 호출이며 새 지도3장이나 독립 코호트가 아니다.

도착점 주변 x6–8/y1–5는 다음과 같다. 문자는 원래 빈칸 위의 표시다.

```text
...
.A.
#G#
.B.
.#.
```

| 도착점 | 중심에서 가장 가까운 벽/경계까지 거리 | 몸체 여유 조건 | 항상 반 칸 결과 | 추가 확인 방식 결과 |
|---|---:|---|---|---|
| G, 원래 위치 | 0.5 | 부족 | 탐색 전 거부 | 탐색 전 거부 |
| A, AI 참고 답 | √0.5≈0.707 | 만족 | 길이9, 검토38 | 길이9, 검토2+38=40 |
| B, 대조 위치 | 0.5 | 부족 | 탐색 전 거부 | 탐색 전 거부 |

원의 반지름0.4에 여유0.15를 더한0.55보다 중심 거리가 커야 한다. B 바로 아래 벽까지0.5라 여유가 부족하다. A에서 가까운 벽은 대각선 모서리로0.707가량 떨어져 있어 이 가정에서 통과한다. 실제 몸체 충돌이나 물리적 안전성을 측정한 것이 아니라 선택된 가상 여유 규칙이다.

A의 끝점이 유효해도 거친 그래프는 여전히 연결 불가였다. 별도 BFS가 거친 거리null, 반 칸18간선(세계 길이9)을 확인한다. 추가 확인 정책은 거친 검토2 뒤 새 반 칸 탐색38로 경로를 얻었다. 유효한 끝점과 경로 도달성은 다른 검사이며, A를 둘 수 있다는 사실만으로 모든 지도에서 도착을 보장하지 않는다. G/B는 INVALID_ENDPOINT_CLEARANCE이고 경로빈배열/길이null/탐색0이다.

## 검증과 기여 범위

원래 G의 저장 결과는 부모 원시 결과와 정확히 같고, 세 도착 설정의 장애물·후보 마스크도 같다. 원래 핵심/몸체/정책/참조 및101개 검사 소스 해시가 같음을 확인했으며 전체 검사는 반복하지 않았다. 새 실행 도구의 구문 검사와6조건 실행을 검증했다.

설정 실행은 실제 탐색3회/검토78/모델7단계/BFS2회/참조852점이다. 추가 검증은852점과3도착점의 거리, BFS2회, 성공 단계36선분·반환36선분, 상태/단계 비용·source/기존TAP·출력 거부/바이트 보존을 확인했고 추가 탐색기는 호출하지 않았다. 같은 경로/입력을 반복 검사한 횟수를 독립 표본으로 세지 않는다.

**도착점을 바꿔 성공한 것은 문제 입력을 바꾼 결과이며 알고리즘 성능 개선이 아니다.** 원래30장과 실패 상태는 유지한다. 목표 위치도 달라졌으므로 서로 다른 목표의 경로 길이를 같은 문제의 개선으로 비교하지 않는다. 최대 허용량은 항상 반 칸100, 추가 확인200이며 시간/에너지/저장량·센서·제어·실제 로봇 측정은 없다.

다음 [입력 수정 연습](../practice/04-goal-placement.mjs)은 AI 참고 답 A를 직접 적용해보는 과제다. 아직 학생 파일 변경이나 실행은 확인하지 않았다. 이후 실제 편집/예측/실행 주체를 확인해 별도로 기록한다. 안내된 좌표 한 줄 편집을 독립 알고리즘 작성이나 독립적인 A 발견으로 확대하지 않는다.
