# 목표 방향의 막다른 길 — 설계 중

무작위 지도 두 묶음에서 나타난 결과가 다른 구조에서도 유지되는지 살펴본다. 목표 쪽으로 향하지만 끝이 막힌 통로를 사례로 정했다. 학생은 두 가지 AI 제안 중 **1번**을 선택했다. 아직 통로 길이, 실행 전 예상, 최종 실험 지도와 결과는 확정하지 않았다.

## AI가 제안한 기본 틀

S는 출발, G는 목표, #은 벽, .은 빈칸이다. 가로 7칸·세로 3칸이며 상하좌우로만 움직인다. 아래쪽 통로를 포함한 기본 틀은 AI 제안이다.

막다른 통로가 S 오른쪽으로 4칸인 후보:

```text
S....#G
.#####.
.......
```

막다른 통로를 2칸으로 줄인 후보:

```text
S..###G
.#####.
.......
```

길이는 S를 제외하고 오른쪽으로 이어지는 빈칸 수다. 두 후보는 첫째 줄의 두 칸만 다르고, 크기·출발점·목표·나머지 벽은 같다.

## 학생이 다음에 정할 항목

막다른 통로 길이를 **2칸 또는 4칸** 중 고른다. 이는 AI 틀 안의 안내된 설계 선택이며, 전체 지도를 독립적으로 설계하거나 코드를 작성한 것으로 기록하지 않는다. 이후 선택한 지도에서 두 A* 동점 규칙의 검토 칸 수에 대한 예상을 실행 전에 남긴다.

설계 초안은 [JSON](../experiments/goal-side-dead-end.design.json)에 기록했다. 후보 준비 중에는 탐색 알고리즘을 호출하지 않았다. 선택과 예상을 기록한 뒤 실행 가능한 입력을 별도로 확정하고, 같은 지도·예산에서 경로 길이와 검토 칸 수를 비교한다. 한 지도 결과를 보편적인 우열로 확대하지 않는다.
