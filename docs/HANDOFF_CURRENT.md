## Two-phase research question
- **Early (question E):** Under paired solvable static grid maps and a fixed node-expansion budget, does A* trade higher compute search for shorter routes relative to Greedy Best-First Search? How does obstacle density change that comparison?
- **RD (question R):** When the selected navigation system is deployed onto a real differential-drive robot with sensor and actuator uncertainty, how closely do its physical outcomes match simulated predictions, and which modifications reduce that gap?

### Important distinction
**Early models grid path planning, not a physically executed robot trajectory.** It cannot measure real collisions, latency from sensing, robot energy usage, real navigation time, localization error, or a true sim-to-real gap. Those appear only in RD after the hardware and protocols exist. Never write that a robot was built when only a grid pathfinder exists.
