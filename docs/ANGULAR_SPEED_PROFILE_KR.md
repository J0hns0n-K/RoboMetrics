# 회전 가속·감속과 중간 정지

학생은 총180도를 한 번에 도는 경우와 중간에 완전히 멈추며90도씩 두 번 도는 경우 중 **2**가 더 오래 걸릴 것으로 [실행 전에 선택](../data/learning/angular-ramp-stop-prediction-01.json)했다. 이유나 수치 예상은 제공하지 않았다. 아래 수식·모델·구현·검사·실행·해석은 AI 지원이다.

## 모델과 단위

[각도 프로필](../src/angular-speed-profile.mjs)은 기존 스칼라 정지→가속→감속→정지 수식을 각도 단위로 감싼 별도 참고 API다. 각도는도, 각속도는도/초, 각가속도는도/초²로 명시한다. 부호 없는 같은 방향 회전만 다루며 각 명령의 시작·끝 각속도는0이다. 중간 정지에 추가 대기 시간을 부과하지 않는다.

각도θ, 최고 각속도ω, 가속·감속 크기α에서 전이 각도는 `ω²/α`다. 짧은 회전은 삼각 속도 프로필로 `2√(θ/α)`초, 긴 회전은 순항을 포함해 `θ/ω + ω/α`초다. 속도와 각도·가속도는 가상 한계이며 측정·보정된 로봇 특성이 아니다. 가속도 자체는 순간적으로 바뀌므로 저크를 제한하지 않는다.

기존 경로 시간 API는 여전히 회전 각속도가 즉시 바뀌는 가정이다. 새 API는 고립된 회전 프로필만 계산하며 경로·휠·자세 적분·주행 제어·센서·미끄러짐·충돌 모델에 연결하지 않았다. 회전각의 의미와 주행 가능한 로봇 운동학은 별도 검증 대상이다.

## 같은 총각도에서의 비교

[설정](../experiments/angular-ramp-stop-01.config.json), [실행 전 프로토콜](../experiments/angular-ramp-stop-01.protocol.json), [실행·검증 원본](../data/learning/angular-ramp-stop-run-01.json), [검사 TAP](../data/learning/angular-ramp-stop-tests-01.tap)는 소스 `f1a9eb1ac7bdf71e199db0e90e33dec5cc1c021b`에 연결된다. 최고 각속도180도/초, 각가속·감속 크기180도/초², 시작·끝 정지, 같은 방향 총180도, 추가 대기0초로 고정했다. 플래너나 탐색 예산은 사용하지 않는다.

| 구성 | 중간 정지 경계 | 각속도 즉시 변화 참고값 | 유한 각가속도 모델 시간 |
|---|---:|---:|---:|
| 180도 한 번 | 0 | 1초 | 2초 |
| 90도씩 두 번 | 1 | 1초 | 약2.83초 |

학생의 선택은 이번 가상 조건에서 지지된다. 중간에 감속해 각속도0이 된 뒤 다시 가속해야 해서 약0.83모델 초가 추가된다. 이는 대기 시간을 따로 더한 결과가 아니다.90도 회전은 최고 각속도에 도달하기 전에 감속하고,180도 회전은 전이 각도에 해당한다. 이 설명을 학생의 이유나 직접 계산으로 기록하지 않는다.

## 확인 범위와 다음 단계

새 각도 검사7개와 기존 직진 프로필12개·속도 램프6개, 총25개가 통과했다. 전체 검사 묶음은 반복하지 않았다. 같은 총각도와 한계, 삼각/순항/정지 프로필, 속도 적분·휴지·연속성·한계·시간표·입력 오류 등을 확인한다. AI가 실습12를 한 번 실행해 두 구성 평가를 보존했고, Python은 별도 시간식과 각도 프로필3개·위상6개를 확인했다. 각 위상은64구간 각속도 적분으로도 확인했다. 기존 소스·검사·원시 결과·TAP 해시는 그대로다.

이는 알려진 해석적 제어 사례이며 새 지도·플래너/BFS 실행·독립 로봇 시행·측정 시간/에너지·최적 경로 증명이 아니다. 다음은 [최고 각속도와 회전 구성을 고정하고 각가속도만 바꿀 때 시간 차이를 먼저 예상하는 과제](../experiments/angular-ramp-accel-sensitivity-01.design.json)다. 새 예상이나 그 조건의 실행 결과는 아직 없다.
