# 제한된 후보군의 실패와 점 지도 도달 가능성

학생은 AI가 제시한 새 지도에서 `↓ ↓ ↓ ↓ → → → ↑`를 [직접 제시](../data/learning/bounded-path-detour-witness-01.json)했다. 이는 안내된 지도에서의 경로 설계이며 지도·변환 코드·실행·최단 길이/시간식 검증은 AI 지원이다. 학생이 직접 수치 시간이나 최단 경로 증명을 제공한 것으로 기록하지 않는다.

## 새 지도와 확인 방법

[입력](../experiments/bounded-path-detour-witness-01.config.json), [실행 전 프로토콜](../experiments/bounded-path-detour-witness-01.protocol.json), [원시 결과·검증](../data/learning/bounded-path-detour-witness-run-01.json)은 소스 `4694255e9c1aa7d51654199ab1bb83ae02111f1e`에 연결된다. 새 지도는4열5행, 출발(0,0), 도착(3,3), 금지 점 칸(1,0)/(1,1)/(1,2)/(1,3)/(2,3)이다. 이전 학생 선택(2,3)은 유지하되 나머지 장벽과 아래 빈줄은 AI가 새로 제안했다. 이전 단일 벽 지도에서 한 요인만 바꾼 실험이나 새로운 독립 지도 코호트가 아니다.

```text
S # · ·
· # · ·
· # · ·
· # # G
· · · ·
```

상하좌우 단위 이동만 허용하고 지도 밖/금지 칸 통과는 거부한다. 물리적 로봇 몸체·여유폭·연속 회전 궤적은 검사하지 않는다. 학생 화살표를 좌표로 옮긴 뒤 유효성을 먼저 확인하고, 유효 경로에만 [직진·회전 가속/감속 모델](BOUNDED_PATH_TIME_KR.md)을 적용한다. 기존6칸 후보20개는 새 지도에서 각각 분류하며 유효 후보가 없어도 그 상태를 `UNREACHABLE`로 바꾸지 않는다.

## 결과

| 확인 항목 | 결과 |
|---|---|
| 보존된6칸 후보군 | 20개 모두 막힘, 유효0개 |
| 학생 우회 경로 | 유효,8번 이동 |
| A* 참고 실행 | 길이8, 검토9개, 예산20 이내 성공 |
| 별도 Python BFS | 최소 이동 횟수8 |
| 학생 경로 모델 시간 | 직진11초 + 회전2초 =13모델 초 |

A*는 기존 `core.mjs`의 점 칸·상하좌우 단위 비용·Manhattan 추정·FIFO 동률 규칙·검토 예산20이다. 시작/도착도 검토 수에 포함한다. Python BFS는 같은 유한 점 그래프를 예산 제한 없이 한 번 확인한 별도 참고 실행이다. 이 길이 검증은 점 그래프의 최소 이동 횟수이며 최소 모델 시간이나 물리적 주행 가능성 증명이 아니다. A*와 Greedy의 우열 비교도 하지 않았다.

모델 시간은 출발 방향down, 직진속도1가상칸/초·선가속/감속1가상칸/초²·각속도180도/초·각가속/감속360도/초²·2번 정지 규칙에서 계산했다. 직진 구간4/3/1칸의 시간5/4/2초와90도 회전2번의2초를 합친 해석적 값이다. 실제 이동/프로그램 시간이나 에너지 측정값이 아니다.

AI는 실습16을 한 번 실행해 학생 시간 계산1개와 A*1회를 기록했다. Python이 학생 화살표·좌표·경계·단위 이동·금지 칸과 후보20개의 완전 분할을 확인하고 BFS1회를 수행했다. 직진/회전 프로필5개·위상12개는 별도 수식·시간표·휴지/한계/연속성·64구간 속도 적분으로 확인했다. 기존 모델/코어/검사·156개 통과 TAP 및 원시 결과 해시가 같아 검사는 반복하지 않았다.

학생의 경로는 제한된6칸 후보가 전부 실패해도 더 긴 길이 존재할 수 있음을 보여 주는 유효한 증인이다. 전체 점 그래프의 도달 불가와 후보군의 소진은 다른 결과다. 이 해석은 AI 검토이며, 학생의 자발적인 일반 규칙이나 증명으로 귀속하지 않는다. 학생은 이후 **안되죠. 가장 최단루트가 8칸인데 당연하지**라고 [단정을 거부하며 이미 제시된8칸 결과를 근거로 설명](../data/learning/bounded-path-coverage-interpretation-01.json)했다. 이는 안내된 사후 해석이고, 독립적인 최단 경로 발견/증명이나 새 탐색 실행으로 기록하지 않는다. 이번 턴에 새 실험은 없다. 학생은 이후 **2**로 A* 대응을 [선택](../data/learning/bounded-path-family-response-choice-01.json)했고 AI가 [별도 정책 API와 네 제어 사례](CANDIDATE_ASTAR_FALLBACK_KR.md)를 구현·확인했다. 후보가 있으면 시간 비교로 고르고, 없을 때만 A*를 호출하며 예산 초과와 전체 점 그래프 소진을 구분한다. 학생은 이유/성능 예상을 제공하지 않았고 코드·실행은 AI 지원이다. A*의 단위 이동 비용 목표는 모델 시간 최소화와 구분한다. 이후 [빈 지도에서 직접 A*와 후보 우선의 모델 시간 비교](CANDIDATE_ASTAR_FALLBACK_KR.md)를 완료했다. 같은 이동 횟수에서도 출발 회전에 따라 모델 시간이 달랐고, 학생은 예상 없이 모른다고 답했다. 실행·설명은 AI 지원이며 다음은 안내된 결과 해석이다.
