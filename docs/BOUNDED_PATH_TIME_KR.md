# 직진·회전 가속과 감속을 합친 경로 시간

학생은 추가 시간이 더 클 경로를 묻는 안내에 **기존?**이라고 답했다. [원문](../data/learning/bounded-path-angular-prediction-01.json)은 기존 X를 고른 잠정 예상으로 기록하며 물음표를 유지한다. 이유·수치 예상·새 코드나 직접 실행을 귀속하지 않는다. 비교에 쓰인 한 번 전환 경로는 [학생의 이전 화살표 설계](../data/learning/linear-accel-route-design-02.json)이며, 이번 합성·한계·검사·실행·해석은 AI 지원이다.

## 기존 모델과 새 참고 모델

[boundedStopTurnTime](../src/bounded-path-time.mjs)은 기존 [직진 가속·감속 경로 모델](LINEAR_ACCEL_PATH_TIME_KR.md)의 동일한 직진 구간·정지 규칙·최소 회전각을 사용한다. 회전 작업에만 [유한 각가속도 프로필](ANGULAR_SPEED_PROFILE_KR.md)을 붙여 전체 시간표를 다시 만든다. 출발 정렬과 모든 중간 회전에 적용하며 도착 후 별도 방향 정렬은 요구하지 않는다. 같은 방향 직선 중간점은 이어 가고, 필요한 정지 지점에서는 직진·회전 속도가0이다. 직진과 제자리 회전은 순차적이며 추가 대기는 없다.

거리D·속도 한계v·가속/감속a의 직진 시간은 짧은 구간 `2√(D/a)`, 순항 구간 `D/v + v/a`다. 각도θ·각속도 한계ω·각가속/감속α의 회전 시간은 `θ ≤ ω²/α`이면 `2√(θ/α)`, 그보다 길면 `θ/ω + ω/α`다. 경로 모델 시간은 직진·회전 작업 시간을 모두 더한 값이다. 각가속도와 선가속도는 별도 단위·한계이며 두 운동을 동시에 수행하지 않는다.

기존 `linearAccelStopTurnTime`의 즉시 각속도 변화 가정과 과거 원시 결과, 점수·플래너·브라우저 기본값은 유지한다. 새 API만 두 종류의 가속·감속을 합친다. 자세·휠 궤적을 시간에 따라 적분하는 로봇 시뮬레이터, 곡선 주행이나 추종 제어를 구현한 것은 아니다.

[설정](../experiments/bounded-path-angular-01.config.json), [실행 전 프로토콜](../experiments/bounded-path-angular-01.protocol.json), [실행·검증 원본](../data/learning/bounded-path-angular-run-01.json), [전체 검사 TAP](../data/learning/bounded-path-angular-tests-01.tap)는 소스 `d4ff097850702502078acfd3f36e9b4cff4fc9ec`에 연결된다. [기존 경로 원본](../data/learning/linear-accel-route-run-02.json)의 좌표와 한계를 고정한다. 두 경로 모두 출발(0,0)·도착(3,3)·거리6, 출발 방향down, 직진속도1가상칸/초·선가속/감속1가상칸/초²·각속도180도/초·2번 정지 규칙이다. 새 모델에만 각가속/감속360도/초²를 추가한다. 장애물 없는 설명용 경로이며 탐색 예산은 사용하지 않는다.

| 경로 | 출발 정렬 포함90도 회전 | 직진 시간 | 기존 회전 시간 | 새 회전 시간 | 기존 총시간 | 새 총시간 | 증가량 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 기존 X `→ ↓ → ↓ → ↓` | 6번 | 12초 | 3초 | 6초 | 15초 | 18초 | 3초 |

위 값은 모두 모델 초이며 실측이 아니다. 이번90도 회전은 새 한계에서1초, 기존 각도/각속도 참고값에서는0.5초다. 따라서 같은 직진 계산을 유지하면서 각 회전마다0.5초가 추가돼 잠정 X 선택을 지지한다. 이 수치·이유는 AI 검토이고 학생이 직접 설명한 것으로 기록하지 않는다. 회전 횟수만으로 모든 경로·회전각·한계의 시간을 결정할 수 있다는 일반 주장도 하지 않는다.

## 확인과 한계

추적된 루트 검사 파일30개의 검사156개가 모두 통과했다. 새 합성 검사8개와 기존 각도·직진·플래너·생성기 검사가 포함된다. 플래너·생성기 회귀 실행은 새 연구 관측으로 세지 않으며, 아래 구성 평가의 호출 수와 구분한다.

AI가 실습13을 한 번 실행해 경로2개×시간 모델2개, 총4개의 보고된 모델 평가를 보존했다. Python이 좌표·단위 이동·직진 구간·출발 정렬·회전각·시간식·증가량·시간표를 따로 재구성했다. 새 합성의 직진 프로필8개·각도 프로필7개, 위상32개를 휴지·연속성·한계·거리/각도와64구간 속도 적분으로 확인했다. 직진 프로필·경로 기하는 두 모델에서 같았고 기존 출력은 보존 원본과 일치했다. 기존 소스·검사·원시 결과·TAP 해시도 변하지 않았다. 구성 평가에는 플래너/BFS나 새 지도가 없다.

이는 가상 한계의 해석적 정지·회전 시간표다. 실제 휠 운동학·동역학·저크·미끄러짐·센서·제어·충돌·물리적 보정·시간/에너지 측정이나 전체 최속 경로를 검증하지 않았다.

## 정해진6칸 후보20개를 빠짐없이 비교

학생은 **없지 않ㄴ나?**라고 [더 빠른 후보가 없을 것이라는 잠정 예상](../data/learning/bounded-path-monotone-prediction-01.json)을 제시했다. 오타·물음표를 유지하며 이유·숫자·증명이나 코드 작성으로 확대하지 않는다. [새 실행](../data/learning/bounded-path-monotone-run-01.json), [프로토콜](../experiments/bounded-path-monotone-enumeration-01.protocol.json), [설정](../experiments/bounded-path-monotone-enumeration-01.config.json)은 소스 `2f254b87a1419e68a95196658ba81591e3b76f8c`에 연결된다. 앞선 합성의 출발/도착·운동 한계를 유지하고 오른쪽3번·아래3번의 모든 순열을 비교했다. 후보 수는 `6중3자리 선택 =20`이며 장애물 없는 설명용 점 경로 한 후보군이다.

| 비교 항목 | 결과 |
|---|---:|
| 고유 후보 | 20개 |
| 학생 경로 시간 | 9모델 초 |
| 더 빠른 후보 | 0개 |
| 같은 시간 후보 | 학생 경로 자신1개 |
| 더 느린 후보 | 19개 |
| 최댓값 | 18모델 초 |

Python은 재귀적 생성과 별도로 오른쪽 이동의 자리 조합을 만들어 정확한 집합 일치·중복 없음·좌표/단위 이동/끝점을 확인했다. 모든 후보의 직진 구간·출발 정렬·내부 회전·시간식을 따로 계산했고 학생/X 기준 결과도 원본과 같았다. 기존 모델·의존성·검사·156개 통과 TAP 해시가 같아 검사를 반복하지 않았다. 새 실행은20개 후보 시간 계산이며20개의 독립 지도나 플래너/BFS 호출이 아니다.

AI가 이번 고정 조건에서 도출한 설명은 다음과 같다. 같은 방향의 연속 구간 수를R, 오른쪽으로 시작하면1이고 아래쪽이면0인 값을I라 두면, 직진 시간은 `6+R`, 회전 시간은 `R−1+I`여서 총 `5+2R+I`모델 초다. 모든 구간은 정수 길이1이상이고 각 내부 회전은90도이기 때문에 이 고정 한계에서 성립한다. 최소R=2와I=0을 만족하는 유일한 순서는 학생의 `↓ ↓ ↓ → → →`로9모델 초다. 이 설명·완전성 검증은 AI 지원이며 학생이 제공한 이유나 증명은 아니다.

따라서 이 후보군에서만 유일 최소임을 확인했다. 더 긴 경로·다른 장애물/몸체/운동 한계·실제 로봇에 대한 전체 최속 증명은 아니다.

## 점 장애물 유효성을 먼저 확인한 비교

학생은 **2**로 [제시된 도착 바로 왼쪽 칸(2,3)](../data/learning/bounded-path-single-wall-choice-01.json)을 골랐다. 이유·새 경로·시간 예상은 제공하지 않았다. [새 실행](../data/learning/bounded-path-single-wall-run-01.json), [프로토콜](../experiments/bounded-path-single-wall-01.protocol.json), [설정](../experiments/bounded-path-single-wall-01.config.json)은 소스 `e907420890593153b1fb73428ebade0d30760426`에 연결된다. 같은 보존 후보20개·ID·좌표·출발/도착·운동 한계에서 점 칸(2,3) 하나만 통과 금지로 추가한다.

각 후보가 벽 칸을 포함하는지 먼저 분류한다. 막힌 후보는 `BLOCKED_POINT_CELL`, 현재 시간은 `null`이고 시간 모델 호출/순위에서 제외한다. 통과 가능한 후보만 `POINT_PATH_VALID`로 시간 계산한다. 과거 장애물 없는 조건의9초 기록은 역사적 원본으로 유지하며 현재의 유효 시간으로 재사용하지 않는다.

| 항목 | 새 점 장애물 조건 |
|---|---:|
| 전체 보존 후보 | 20개 |
| 막힌 후보 | 10개 |
| 통과 가능한 후보 | 10개 |
| 이전 학생 최솟값 경로 | 막힘 / 현재 시간null |
| 유효 후보군의 유일 최소 | `→ → → ↓ ↓ ↓`,10모델 초 |

이는 후보 유효성 분할이지10/20지도 성공률이 아니다. Python은 독립적인 조합 집합·좌표·칸 포함 여부·완전 분할을 확인했고, 금지 칸(2,3)을 지나는 후보 수 `C(5,2)×C(1,1)=10`도 일치했다. 유효 후보10개는 구간·각도·시간식을 따로 확인했고 기존 빈 조건과 시간이 같았다. 이전 학생 경로는 금지 칸을 지나 현재 사용 불가이고, 다른 유효 경로의10모델 초가 새 후보군 최소다. 이 해석은 AI 지원이며 학생이 설명/예측한 것으로 기록하지 않는다.

기존 모델·의존성·검사·156개 통과 TAP 및 원시 결과 해시가 같아 검사를 반복하지 않았다. 새 실행은 후보 유효성20개 확인과 유효 시간10개 계산이며, 막힌 후보 시간 계산0개·플래너/BFS0개다. 새 독립 지도 코호트·물리적 로봇 몸체/연속 궤적 충돌 검사·제어·보정·측정 시간/에너지·모든 경로의 최속 증명이 아니다. 학생은 이후 **장애물이 있었으니까**라고 [짧게 설명](../data/learning/bounded-path-wall-interpretation-01.json)했다. 이는 결과를 본 뒤의 안내된 질적 귀속으로 기록하고 구체 위치·상태·시간·일반 규칙이나 증명을 학생에게 추가로 귀속하지 않는다. 세부 유효성 해석은 AI 검토다. 이후 학생은 새4열5행 점 지도에서 `↓ ↓ ↓ ↓ → → → ↑`를 만들었고, [후보군 범위 확인](POINT_PATH_COVERAGE_KR.md)은6칸 후보20개가 모두 막혀도 학생의8칸 경로는 유효함을 확인했다. 별도 BFS의 최소 이동 횟수8과 일치하며 모델 시간은13초다. 길이 최소와 모델 시간 최소/물리적 가능성은 구분한다. 학생은 [이미 제시된8칸 최소 경로를 근거로 도착 불가 단정을 거부](../data/learning/bounded-path-coverage-interpretation-01.json)했다. 안내된 사후 설명이지 새 발견/증명/실행은 아니다. 학생은 이후2번 A* 대응을 선택했고 AI가 [별도 후보/A* 정책](CANDIDATE_ASTAR_FALLBACK_KR.md)을 확인했다. 등록 후보의 최소 모델 시간과 A*의 최소 이동 횟수는 다른 목표다. [같은 빈 지도의 직접 A* 비교와 검증](CANDIDATE_ASTAR_FALLBACK_KR.md)은 같은6칸에서도 출발 방향 정렬 때문에 모델 시간이 달라짐을 확인했다. 학생은 모른다고 답했고 비교·설명은 AI 지원이다. 학생은 이후 출발 방향 때문이라고 안내된 해석을 제공했다. [후속 직선 구간 길이 비교](EQUAL_TURN_RUN_LENGTHS_KR.md)는 출발 방향·이동·회전 횟수까지 같아도 정지 위치에 따라 모델 시간이 달라질 수 있음을 주어진 가상 조건에서 확인했다. 같은 두 경로의 최고 속도만 낮춘 후속 비교에서는 모델 시간이 같아졌다. 효과는 운동 한계에 따라 달라지며 상세 조건·원본은 위 후속 비교에 연결돼 있다. 다음은 로봇을 받은 뒤의 첫 보정 대상 선택이다.
