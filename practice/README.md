# 첫 파일 수정 연습

`01-path-change.mjs`는 AI가 제공한 산술 연습 예제다. 실제 경로 탐색이나 새 연구 결과가 아니라, 코드에서 실험 입력을 직접 바꾸는 연습이다.

1. `const after = 4;`를 `const after = 10;`으로 바꾸고 저장한다. `before = 8`은 유지한다.
2. 실행하기 전에 결과 숫자와 이동 거리가 늘었는지 줄었는지를 예상해 적는다.
3. 저장했다고 알려 주면 변경한 줄을 함께 확인하고 실행한다. 실행 명령은 `node practice/01-path-change.mjs`다.

파일 제공과 예제 구현은 AI 지원이다. 학생이 실제 저장한 변경, 실행 전 예측, 실행 주체는 확인한 뒤 별도로 기록한다. 이 산술 예제 자체는 경로 탐색 알고리즘 개선이 아니다.

첫 저장 시도: 사용자는 `저장했어/2`라고 답했지만, 파일은 `before = 10`, `after = -8`이었다. AI가 이 상태를 별도 커밋으로 보존한 뒤 실행한 결과는 -18이다. 이후 사용자가 안내에 따라 `before = 8`, `after = 10`으로 수정·저장한 것이 확인됐고, AI가 재실행한 결과는 2였다. 계산 방법과 정답을 설명한 뒤의 안내된 수정이므로 새로운 독립 예측으로 취급하지 않는다. 두 시도의 입력·출력·실행 주체는 `01-attempt-log.md`와 `data/learning/practice-01-attempt-0*.json`에 각각 보존했다.
